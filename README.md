Гибридная система для одновременного измерения мышечной силы и активации мышц.

## 📦 Компоненты

- **ESP32-S3** — 240MHz двухядерный микроконтроллер
- **HX711** — датчик весов (до 10 кг)
- **AD8232** — датчик мышечной активности (EMG)
- **OLED 128x64** — реал-тайм дисплей
- **Wi-Fi AP** — веб-интерфейс мониторинга
- **EEPROM** — сохранение коэффициентов калибровки

## ⚙️ Как работает

### Основной процесс (каждые 100 мс)

```
┌─────────────────────────────────────┐
│ 1. Читаем вес (HX711, 10Hz)        │
│    ↓ Адаптивная фильтрация EMA    │
│ 2. Обрабатываем EMG (500Hz → 256 выборок)  │
│    ↓ Вычисляем: Min, Max, Avg, Peak, RMS  │
│ 3. Обновляем OLED дисплей          │
│ 4. При записи: сохраняем точку CSV │
└─────────────────────────────────────┘
```

### Калибровка EMG (автоматическая)

При включении: первые 3 сек система измеряет baseline при расслабленной мышце, потом может регистрировать AC сигнал (активацию).

### Режим записи

```
START REC → Собираем: Time(ms), Weight(g), Peak, RMS, Raw → STOP & DOWNLOAD → CSV файл
```

### Веб-интерфейс (http://192.168.4.1)

| Кнопка | Функция |
|--------|---------|
| **TARE** | Отнулить весы |
| **CALIB** | Откалибровать по известному весу (введите вес в граммах) |
| **START REC** | Начать запись данных |
| **STOP & DL** | Остановить и скачать CSV файл |

**Статус внизу**: `Ready: [W✓] [E✓] Idle`
- `[W✓]` — весы откалиброваны
- `[E✓]` — EMG готов
- `Idle` / `Recording...` — состояние


```
TARE       - Отнулить весы
CAL 1000   - Откалибровать по 1000g
REC        - Начать запись
STOP       - Остановить запись
STAT       - Статистика
EMG        - Статус EMG
HELP       - Справка
```

## 🔌 Подключение GPIO

```
HX711:  GPIO8 (DOUT) + GPIO9 (SCK)
EMG:    GPIO4 (SIG)
OLED:   GPIO20 (SDA) + GPIO21 (SCL)
```
